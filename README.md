# Webloom Interactive

Website for **Webloom Interactive** — a creative technology studio and a concern of Dcastalia Limited.

Built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Three.js / React Three Fiber, GSAP + ScrollTrigger, Motion, Lenis, anime.js and Chart.js.

## Highlights

- **Hero "loom"** — ~15k WebGL particles assemble into the Webloom W-mark, scatter around the cursor, and unravel into a woven landscape on scroll.
- **Scroll choreography** — Apple-style word-fill statement, pinned horizontal expertise cards, a 3D laptop that tilts open and cycles through studio concepts, stacking process cards.
- **Playground** — six live experiments (Three.js, GSAP, Motion, Lenis, anime.js, Chart.js).
- Custom cursor, magnetic buttons, intro loader, page curtain transitions, motion pause toggle, `prefers-reduced-motion` support.

All copy lives in `src/lib/content.ts`.

## Develop

npm install
